# Tipos numéricos
- int para numeros sem ponto flutuante (%d)
- float e double para ponto flutuante (%f ou lf)
- para formatação de tipos flutuantes, podemos colocar após o percent um "." e após a quantidade de casas após a vírgula que será printada
 
# Tipos alfanuméricos
- caracteres para símbolos singulares (%c)
- string* (que não existe esse tipo de dado em c) 

# Tipos booleanos
- valores diferentes de zero sempre serão lidos como verdadeiros
- valores que são iguais a zero são lidos como falso

# Operações matemáticas
- somar: +
- subtrair: -
- dividir: /
- resto da divisão: %
